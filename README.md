\section{Overview}
The Crochet Calendar App is a specialized productivity tool for crochet enthusiasts, combining a traditional event calendar with project and pattern management. It is built using Modern Android development practices, including Jetpack Compose, Room Database, and Kotlin Coroutines.

\section{Room Database Structure}
The application uses Room for persistent storage of user data. The database is defined in \texttt{com.crochet.calendar.data.CalendarDatabase}.

\subsection{Entities}
The database consists of four primary entities:
\begin{itemize}
    \item \textbf{Event}: Stores calendar events including name, date, time, and optional project links.
    \item \textbf{Project}: Represents a crochet project. Tracks the current component and progress steps.
    \item \textbf{Pattern}: Stores pattern metadata such as name, notes, and color tags.
    \item \textbf{Component}: Represents specific parts of a pattern (e.g., ``Sleeve'', ``Body'').
\end{itemize}

\subsection{Relationships}
\begin{itemize}
    \item \texttt{Event} has a foreign key to \texttt{Project} (SET\_NULL on delete).
    \item \texttt{Project} has a foreign key to \texttt{Pattern} (CASCADE on delete).
    \item \texttt{Component} has a foreign key to \texttt{Pattern} (CASCADE on delete).
\end{itemize}

\section{Calendar Logic}
The core calendar operations are handled by the \texttt{CalendarLogic} class (found in \texttt{CalenderLogic.kt}).

\subsection{Core Features}
\begin{itemize}
    \item \textbf{Date Management}: Tracks \texttt{curMonth}, \texttt{curDay}, and \texttt{curYear}. Handles month transitions and leap year calculations.
    \item \textbf{Holiday System}: Includes a robust holiday engine that manages both fixed-date holidays (e.g., Christmas) and moveable holidays (e.g., Easter-based holidays, Labor Day).
    \item \textbf{Easter Calculation}: Uses a specialized algorithm to determine the date of Easter Sunday for any given year.
    \item \textbf{Persistence Integration}: Interfaces with \texttt{Prefs} to save and load custom holidays and birthdays.
\end{itemize}

\section{General Screens}
The UI is divided into three main tabs, managed by \texttt{AppRoot} and \texttt{Tab} enum.

\subsection{Calendar Tab}
The primary interface for viewing and adding events, birthdays, and holidays.
\begin{itemize}
    \item \textbf{CalendarGrid}: A custom Compose implementation of a month view.
    \item \textbf{Thread View}: Displays events for the selected day in a vertical timeline style (``Today's Thread'').
    \item \textbf{Sub-Screens}: Specialized views for \texttt{All Events}, \texttt{All Holidays}, and \texttt{All Birthdays}.
\end{itemize}

\subsection{Projects Tab}
Allows users to manage their crochet projects.
\begin{itemize}
    \item \textbf{ProjectsScreen}: Lists all active projects and their associated patterns.
    \item \textbf{Progress Tracking}: Visual feedback on project completion using components and steps.
\end{itemize}

\subsection{Patterns Tab}
A library for the user's patterns.
\begin{itemize}
    \item \textbf{PatternScreen}: Displays patterns as cards.
    \item \textbf{Component Management}: Allows users to define and reorder components for each pattern.
\end{itemize}

\section{Building and Running}
The project uses the \texttt{com.crochet.calendar} package. Note that the data-related classes are located in the \texttt{com.crochet.calendar.data} package (recently renamed from \texttt{Data} for compatibility).
